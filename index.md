# edu-operations-research

Добро пожаловать в учебный проект по исследованию операций.

Здесь один и тот же набор материалов доступен в двух режимах:

- как обычный GitHub-репозиторий с numbered-папками;
- как опубликованный сайт GitHub Pages для последовательного чтения.

## Как пользоваться проектом

1. Если вы хотите читать материалы по порядку, используйте левую навигацию сайта.
2. Если вам важны исходники ноутбуков и markdown-файлов, переходите по ссылкам на GitHub-репозиторий.
3. Если вы выполняете лабораторные самостоятельно, сначала проходите теорию, затем основной ноутбук, затем самостоятельный вариант.

## Текущая структура

- **ЛР-01**: основы линейного программирования, геометрический и программный подход.
- **ЛР-01.1**: прикладной primal-dual кейс по госзакупкам и приоритизации проверки.
- **ЛР-02**: транспортная задача, баланс спроса и предложения, фиктивные узлы и проверка через `scipy.optimize.linprog`.

## Roadmap

- **ЛР-03 (draft)**: двойственность и анализ чувствительности. Черновые материалы уже есть в репозитории, но ещё не входят в опубликованную основную навигацию.

## Локальная сборка

```bash
uv sync --group authoring --group docs
uv run python scripts/validate_notebooks.py
uv run jupyter nbconvert --to notebook --execute --inplace 02-lab-transport-problem/lab_02_transport_problem.ipynb
uv run jupyter-book build . --warningiserror
```

Материалы доступны для чтения, но не для свободного переиспользования.

Подробные ограничения и процедура запроса разрешения описаны в `LICENSE.md` и `PERMISSIONS.md`.
