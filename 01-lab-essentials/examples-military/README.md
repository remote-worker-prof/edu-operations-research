# ЛР-01: Разобранные военные примеры

Здесь лежат полностью решённые военные examples для ЛР-01.

## Состав блока

- `lab_01_example_military_01.ipynb` — комплектование аварийных энергетических наборов
- `lab_01_example_military_02.ipynb` — распределение сервисных комплектов для генераторов
- `lab_01_example_military_03.ipynb` — комплектование медицинских наборов поддержки

Военные examples используют ту же математику базового ЛП, но в другой прикладной оболочке.
