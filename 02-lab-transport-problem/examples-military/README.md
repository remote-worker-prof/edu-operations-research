# ЛР-02: Разобранные военные примеры

Здесь лежат три полностью решённых военных transport examples.

## Состав блока

- `lab_02_example_military_01.ipynb` — рационы и медкомплекты
- `lab_02_example_military_02.ipynb` — ротация топливного резерва
- `lab_02_example_military_03.ipynb` — маршрутизация медико-эвакуационного снабжения

Военные examples показывают те же транспортные принципы на сценариях обеспечения и логистики.
