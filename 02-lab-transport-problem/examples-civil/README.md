# ЛР-02: Разобранные гражданские примеры

Здесь лежат три полностью решённых гражданских transport examples.

## Состав блока

- `lab_02_example_civil_01.ipynb` — лекарства в больницы
- `lab_02_example_civil_02.ipynb` — учебные материалы и оборудование
- `lab_02_example_civil_03.ipynb` — школьные автобусные запчасти

Эти notebooks нужны как образец постановки, сборки `A_eq` и интерпретации маршрутов.
