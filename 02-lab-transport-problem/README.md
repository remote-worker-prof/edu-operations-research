# ЛР-02: Транспортная задача

Кратко: в этой лабораторной студенты переходят от общей постановки линейного программирования к специальной, очень прикладной модели распределения потоков между поставщиками и потребителями.

## Что изучаем

- транспортную задачу как частный случай ЛП;
- баланс запасов и спроса;
- закрытую и открытую постановки;
- фиктивного поставщика и фиктивного потребителя;
- подготовку данных для `scipy.optimize.linprog`;
- проверку допустимости и интерпретацию оптимального плана перевозок.

## Что сознательно не включаем

- транспортный симплекс;
- метод северо-западного угла как основной объект изучения;
- MODI, Vogel и другие табличные эвристики.

Фокус этой работы: корректная постановка, понятная интерпретация и воспроизводимая проверка решения в Python.

## Структура папки

- `theory_transport_problem.md` — подробная теория и методические заметки;
- `lab_02_transport_problem.ipynb` — основной разобранный пример;
- `lab_02_part2_variants.ipynb` — самостоятельные варианты без готовых ответов;
- `eor-issue.md` — ссылка на рабочую задачу Beads и команда fallback.

## Базовый кейс

Основной разобранный пример построен вокруг гражданской логистики: три аптечных склада распределяют партии лекарств по четырём больницам. На этом кейсе удобно показать:

1. как формируется матрица затрат;
2. почему нужно проверять баланс запасов и спроса;
3. как разворачивать матрицу перевозок в вектор для `linprog`;
4. как потом вернуть решение обратно в таблицу поставок.

## Самостоятельные варианты

Во второй части лабораторной собраны шесть сценариев:

- 3 гражданских;
- 3 военных;
- минимум по одному гражданскому и военному варианту с очень дорогим маршрутом для содержательной интерпретации;
- минимум два небалансных кейса, где нужно добавить фиктивный узел.
