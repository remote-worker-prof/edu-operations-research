# ЛР-04: Задача о назначениях

Эта лабораторная посвящена модели назначений: каждому исполнителю назначается ровно одна задача, и каждая задача получает ровно одного исполнителя. Цель — минимизировать суммарные затраты (время, риск, штраф, стоимость).

## Единый учебный маршрут

1. Сначала прочитайте теорию.
   Результат этапа: вы понимаете постановку, ограничения «один к одному» и смысл итогового критерия.
2. Затем решите свой ноутбук для самостоятельной работы в корне папки.
   Результат этапа: у вас есть `row_ind`, `col_ind`, `assignment_df`, `total_cost`, проверки `assert` и краткая интерпретация.
3. После самостоятельной попытки откройте разобранный пример в `examples-civil/` или `examples-military/`.
   Результат этапа: вы сверяете логику шагов, проверяете расчёты и формулируете итоговый вывод в том же формате.

## Рабочие тетради студента

- `lab_04_student_civil_01.ipynb` — выездные бригады по районам
- `lab_04_student_civil_02.ipynb` — преподаватели по учебным группам
- `lab_04_student_military_01.ipynb` — ремонтные бригады по единицам техники
- `lab_04_student_military_02.ipynb` — экипажи по задачам вылета

## Разобранные примеры

- `examples-civil/` — 3 полностью разобранных гражданских примера по модели назначений
- `examples-military/` — 3 полностью разобранных военных примера по модели назначений

## Что студент должен уметь после ЛР-04

- собирать матрицу затрат для модели «один к одному»;
- решать задачу о назначениях через `scipy.optimize.linear_sum_assignment`;
- выполнять LP-проверку через `scipy.optimize.linprog` и сопоставлять результаты;
- проверять ограничения «один к одному» через `assert`;
- интерпретировать итоговое назначение и суммарный критерий в прикладных терминах.
