# ЛР-04: Разобранные военные примеры

Здесь находятся три полностью разобранных военных примера по задаче о назначениях.

## Как использовать блок примеров

1. Сначала решите свой ноутбук для самостоятельной работы.
2. Затем откройте соответствующий разобранный пример.
3. Сравните структуру решения шаг за шагом: данные → решение методом Венгера → LP-проверка → мини-сценарий → вывод.

Результат работы с блоком: вы уверенно переносите математическую логику в сценарии оперативного планирования.

## Состав блока

- `lab_04_example_military_01.ipynb` — назначение ремонтных бригад на бронетехнику
- `lab_04_example_military_02.ipynb` — назначение экипажей БПЛА на миссии
- `lab_04_example_military_03.ipynb` — назначение расчётов связи на узлы развёртывания
