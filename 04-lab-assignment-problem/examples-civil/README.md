# ЛР-04: Разобранные гражданские примеры

Здесь находятся три полностью разобранных гражданских примера по задаче о назначениях.

## Как использовать блок примеров

1. Сначала решите свой ноутбук для самостоятельной работы.
2. Затем откройте соответствующий разобранный пример.
3. Сравните структуру решения шаг за шагом: данные → решение методом Венгера → LP-проверка → мини-сценарий → вывод.

Результат работы с блоком: вы понимаете не только вычисление, но и способ объяснения решения в отчёте.

## Состав блока

- `lab_04_example_civil_01.ipynb` — назначение аварийных бригад на районы
- `lab_04_example_civil_02.ipynb` — назначение преподавателей на экзаменационные группы
- `lab_04_example_civil_03.ipynb` — назначение инженерных команд ЖКХ на объекты
