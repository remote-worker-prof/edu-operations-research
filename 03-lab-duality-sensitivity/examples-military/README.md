# ЛР-03: Разобранные военные примеры

Здесь лежат три полностью решённых военных examples по двойственности и анализу чувствительности.

## Состав блока

- `lab_03_example_military_01.ipynb` — бюджет полевой связи
- `lab_03_example_military_02.ipynb` — бюджет топливного резерва
- `lab_03_example_military_03.ipynb` — бюджет медицинской эвакуационной поддержки

Военные examples используют ту же логику duality + sensitivity, но в сценариях ресурсного планирования обеспечения.
