# ЛР-03: Разобранные гражданские примеры

Здесь лежат три полностью решённых гражданских examples по двойственности и анализу чувствительности.

## Состав блока

- `lab_03_example_civil_01.ipynb` — базовый пример распределения публичного бюджета
- `lab_03_example_civil_02.ipynb` — образовательные программы региона
- `lab_03_example_civil_03.ipynb` — муниципальная готовность к ЧС

Эти notebooks показывают, как шаг за шагом переходить от прямой модели к теневым ценам и сценарному анализу.
